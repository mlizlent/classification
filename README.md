# Classification Exercises

This repository contains a series of Jupyter notebooks for classification exercises (ex00 to ex06). The notebooks explore various machine learning classification techniques and algorithms.

## Contents

- **ex00/Notebook_ex00.ipynb** - Introduction/setup
- **ex01/Notebook_ex01.ipynb** - Basic classification concepts
- **ex02/Notebook_ex02.ipynb** - Model evaluation metrics
- **ex03/Notebook_ex03.ipynb** - Advanced classification techniques
- **ex04/Notebook_ex04.ipynb** - Model comparison
- **ex05/Notebook_ex05.ipynb** - Real-world dataset application
- **ex06/Notebook_ex06.ipynb** - Final project/summary

## Data

The `breast-cancer-wisconsin.data` file contains the dataset used for the classification exercises.

## Setup

To run the notebooks, you will need to install the required dependencies. You can find them in the `requirements.txt` file in the `ex00` directory.

```bash
pip install -r ex00/requirements.txt
```

## Usage

Open the notebooks in Jupyter and run them cell by cell to follow along with the exercises.
